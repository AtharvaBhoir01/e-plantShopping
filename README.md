# e-plantShopping

## Paradise Nursery Shopping Application

A React-based online houseplant shopping application where users can browse plants, add items to their cart, adjust quantities, and view the total cost.

### Features
- Browse plants by category
- Add plants to the shopping cart
- Increase or decrease quantities
- Remove items from the cart
- View total prices
- Navigate between Home, Plants, and Cart pages

### Technologies
- React
- Redux Toolkit
- React Redux
- Vite
